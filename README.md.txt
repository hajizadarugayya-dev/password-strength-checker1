# 🔐 Şifrə Gücü Test Edicisi

Bu layihə istifadəçinin daxil etdiyi şifrənin təhlükəsizlik səviyyəsini qiymətləndirir.

## 🎯 Öyrədiklərim
- Regex (nizamlı ifadələr) ilə mətn analizi
- Şifrə təhlükəsizliyi əsasları
- String manipulyasiya
- Modul proqramlaşdırma

## 🚀 İstifadə qaydası
```bash
python password_checker.py

## 📊 Qiymətləndirmə meyarları

| Meyar | Açıqlama |
|-------|---------|
| Uzunluq | 8+ simvol (yaxşı), 12+ simvol (çox yaxşı) |
| Böyük hərf | A-Z arası ən azı 1 simvol |
| Kiçik hərf | a-z arası ən azı 1 simvol |
| Rəqəm | 0-9 arası ən azı 1 simvol |
| Xüsusi simvol | !@#$%^&*() kimi simvollar |

⚠️ Qeyd
Bu proqram yalnız təhsil məqsədi daşıyır. İcazəsiz istifadə qanunsuzdur.
